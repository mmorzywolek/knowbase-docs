# Web Search

Web Search lets you search specific website domains directly from chat — useful for documentation sites, knowledge bases, or internal wikis.

## Setting up

1. Go to **Account > Connectors**
2. Under **Web Search**, click **Add domain**
3. Enter the domain (e.g., `docs.example.com`)

<!-- screenshot: web-search-add-domain -->

## Using in chat

Toggle the **Web** icon in the chat input bar. Knowbase searches your configured domains and includes relevant web content in answers.

{% hint style="info" %}
**Plan requirement:** Web Search is available on Pro and Team plans.
{% endhint %}
