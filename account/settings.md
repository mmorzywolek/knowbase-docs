# Settings

Access settings from the **user icon** in the top right corner of the app.

## Profile

View your email address and current plan.

## Connectors

Connect and manage external services:
- Google Drive
- Notion
- Dropbox
- Web Search domains

See [Connectors](../connectors/README.md) for setup guides.

<!-- screenshot: settings-connectors-tab -->

## Shared Chats

View all active share links. See message count and last activity for each. Delete links to revoke access.

## API Access

Generate and manage your API key. See [API Reference](../api/README.md) for documentation.
