# Library

The Library is where all your uploaded files live. Go to the **Library** tab to see everything you've added.

<!-- screenshot: library-grid-view -->

## Views

Switch between **Grid view** (cards) and **List view** (table) using the toggle in the top right.

## Filtering

Use the filter chips to narrow by file type:
- All, PDFs, Videos, YouTube, Audio, Documents, Channels, Websites, Presentations

<!-- screenshot: library-filter-chips -->

## File actions

Click the **three-dot menu** on any file to:
- **Open** — view the file and chat with it
- **Rename** — change the display name
- **Share** — generate a share link
- **Download** — download the original file
- **Delete** — permanently remove the file

<!-- screenshot: library-file-menu -->

## Opening a file

Click any file to open it. You'll see:
- The file content (document viewer, video player, or transcript)
- A chat panel on the right where you can ask questions about this specific file
