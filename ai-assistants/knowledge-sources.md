# Knowledge Sources

## Source modes

Your assistant can search either:

- **Entire library** — searches all your uploaded files. New uploads are automatically included.
- **Specific files** — only searches the files you select.

<!-- screenshot: sources-mode-selection -->

## Selecting specific files

When you choose "Specific files":

1. Browse your library with search and filters
2. Check the files you want to include
3. Save your selection

<!-- screenshot: sources-file-picker -->

{% hint style="info" %}
**Tip:** Use "Entire library" if you want the assistant to always have access to your latest uploads. Use "Specific files" if the assistant should only know about certain documents.
{% endhint %}
