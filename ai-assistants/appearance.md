# Appearance & Widget

## Widget mode

Choose how the assistant appears on your website:

- **Bubble** — a floating chat button in the corner that expands into a popup
- **Panel** — a slide-in side panel triggered by a bottom bar

<!-- screenshot: appearance-mode-selector-with-preview -->

## Customization options

| Setting            | Description                                      |
| ------------------ | ------------------------------------------------ |
| **Color**          | Primary color for the widget header and buttons  |
| **Title**          | Name shown in the chat header                    |
| **Greeting**       | Welcome message displayed when chat opens        |
| **Starter questions** | Suggested questions shown as chips (comma-separated) |

<!-- screenshot: appearance-live-preview -->

The live preview on the right updates in real time as you make changes.

{% hint style="info" %}
**Changes apply instantly** — once saved, your deployed widget picks up the new appearance without updating the embed code.
{% endhint %}
